Claude 的登录方式和很多服务不一样：它不依赖你记住的密码，而是每次登录往你邮箱发一个一次性验证码（或一个登录链接），你把码填回去就进去了。好处是不用记密码、也不怕密码泄露；坏处是**邮件收不到，你就彻底进不去**——没有"用密码登录"这条备用路径。

这也让"收不到验证码"从一个注册期的一次性麻烦，变成了一个**每次登录都可能复现**的问题。本文按发生顺序给一份可以照着做的清单。

## 一、先确认你等的是什么

Claude 的邮件登录通常会同时给你两样东西：一串 6 位数字的验证码，和一个可以直接点的登录链接。两者作用相同，用哪个都行。

三个关键事实，先记住：

| 事实 | 意味着 |
| --- | --- |
| 验证码有效期很短（通常十几分钟） | 收到后立刻用，别放着先去忙别的 |
| 重新发送会让旧码作废 | 只用**最新**一封，旧邮件里的码一定是错的 |
| 码与请求它的那个会话绑定 | 在 A 浏览器请求，就在 A 浏览器填 |

最后一条是很多人栽跟头的地方：**在电脑上点了"发送验证码"，然后在手机上打开邮件、点了邮件里的登录链接**——手机上登进去了，电脑那个窗口还在等。反过来也一样：手机请求的码，填到电脑窗口里可能直接报无效。

**所以第一件事**：如果你已经反复发了好几次，先把所有窗口关掉，回到同一台设备、同一个浏览器，重新发一次，只用最新那封。

## 二、等够 5 分钟，再去找信

正常到达是 30 秒到几分钟。不到 5 分钟就狂点重发，只会让每一封新邮件作废掉前一封，同时触发发信频率限制。

等满之后，按这个顺序找（**用搜索，别翻文件夹**）：

```
邮箱搜索框输入 "anthropic" 或 "claude"
搜索范围一定选「全部邮件」，不是「收件箱」
↓ 没有，再逐个看：
垃圾邮件 / 垃圾箱
推广、社交等自动分类标签（Gmail）
其他 / Other（Outlook 的重点收件箱之外）
归档、全部邮件
过滤器与规则（有没有把它移走或直接删了）
```

**如果你用的是第三方邮件客户端**（Outlook 桌面版、Foxmail、系统邮件 App），一定要去**网页版**再看一遍。客户端的本地规则和同步延迟，是"服务器上明明有、你却看不到"的常见原因。

在垃圾箱找到了：先标记"非垃圾邮件"，再用里面的码。有些邮箱在垃圾箱里会重写或禁用链接，直接点可能失败；数字验证码则不受影响，可以直接复制。顺手把发件域名加进白名单，下次就不会再被拦。

## 三、还是没有：这几类邮箱天然容易丢信

找遍确实没有，问题基本在邮箱这一端。

**国内邮箱（QQ、163、126 等）对境外发信源拦截率偏高**，而且经常是静默丢弃——不进垃圾箱、不退信，就是没有。这不是配置能完全解决的问题。Claude 的登录码属于高频事务邮件，一旦这个邮箱有拦截倾向，你会变成三次登录两次收不到，极度影响使用。

**公司或学校邮箱有额外的安全网关**，含外部链接的邮件可能被隔离在 IT 后台，你的邮箱里什么都看不到。

**别名、转发、临时邮箱**：iCloud 隐藏邮件地址、Firefox Relay、各类一次性邮箱，都在转发链路上多了一跳，丢信和延迟的概率显著上升。临时邮箱的域名还大多在公开黑名单上。

对应的判断很直接：**满足上面任意一条，别修了，换邮箱。** 优先选境外主流邮箱服务的**主地址**（Gmail、Outlook 等），不带别名、不带加号、不套转发。这类邮箱和境外服务之间的投递链路最短。

换之前先做个 30 秒的自测：**用另一个邮箱给这个邮箱发一封带链接的普通邮件**。连自己发的信都收不到，说明是邮箱本身的收信问题，跟 Claude 无关。

换邮箱的代价要提前知道：**Claude 账号和邮箱是绑定的，换邮箱等于换账号**，原账号的对话记录、订阅状态不会自动跟过去。如果原账号已经开了订阅，不要直接注册新账号，先走官方支持问换绑路径。**这也是为什么第一次注册就该用一个长期稳定的邮箱**——相关权衡在 [ChatGPT 注册用什么邮箱更稳](/blog/cn-chatgpt-email-choice-guide/) 里讲过，判断逻辑对 Claude 完全适用。

## 四、收到了却用不了

| 提示 | 原因 | 处理 |
| --- | --- | --- |
| 验证码无效 | 用了旧邮件里的码 | 按时间找最新一封 |
| 验证码已过期 | 超出有效期 | 重发，收到后立即填 |
| 链接打开空白 | 浏览器扩展拦截脚本 | 复制链接到无痕窗口打开 |
| 链接提示无效请求 | 邮箱客户端重写/截断了 URL | 用 6 位数字码，别点链接 |
| 填完码又跳回登录页 | Cookie / 会话问题 | 见下一节 |
| 提示请求过于频繁 | 触发限流 | 停手等 30 分钟以上 |

**链接被重写是个隐蔽的坑**：部分企业邮箱和手机邮件 App 会把原始链接替换成自家的安全跳转地址，跳转后参数丢失，就报无效请求。**遇到这种情况直接改用 6 位数字码**，它不受链接重写影响，是更稳的那条路。

## 五、码填对了还是进不去

如果验证码接受了，却又弹回登录页，问题已经不在邮件上了，而在浏览器会话：

- **Cookie 被禁用或第三方 Cookie 被严格拦截**。Safari 的"阻止跨站跟踪"、Firefox 的严格增强保护都可能导致登录状态存不住。临时对该站点放行。
- **浏览器扩展干扰**。先用无痕窗口验证一次：无痕能登、正常窗口不能登，就回去逐个禁用扩展定位。
- **系统时间偏差过大**。令牌校验对时间敏感，把系统时间设为自动同步。
- **登录中途切换了网络出口**。请求验证码和提交验证码之间换了网络，会话对不上。**全程保持网络环境不变**，这比选哪个环境更重要。

还有一类是**地区可用性**问题：如果页面明确提示所在地区不受支持，那不是验证码的问题，重发一百次也没用。这种情况见 [Claude 国内直接访问现状（2026）](/blog/cn-claude-cn-direct-access-2026/)。

## 六、一页纸清单

```
1. 关掉所有多余窗口，回到同一设备同一浏览器
2. 发送验证码 → 等满 5 分钟（别重发）
3. 邮箱全局搜 anthropic / claude，范围选「全部邮件」
   → 垃圾箱 / 推广 / 归档 / 过滤规则都看一遍
   → 用网页版再看一次
4. 找到了：只用最新一封；在垃圾箱就先标「非垃圾邮件」
   优先复制 6 位数字码，而不是点链接
5. 没找到：加白名单 → 重发 1 次 → 再等 5 分钟
6. 仍没有：自测邮箱收信是否正常
   → 邮箱本身有问题，或属于国内邮箱/企业邮箱/别名邮箱
   → 换境外主流邮箱主地址（注意：换邮箱=换账号，有订阅先问官方换绑）
7. 码能填但登不进：无痕窗口 + 允许 Cookie + 校准系统时间 + 全程不切网络
```

全程控制在半小时内。**任何时候看到"请求过于频繁"就立刻停手**，继续点只会把冷却时间越拉越长，而且高频重试本身就是风控模型关注的特征。

最后一条通用提醒：**验证码就是你账号的钥匙**。不要把 6 位数字、登录链接、邮箱密码发给任何人，包括自称客服或"代登录"的。正规支持渠道永远不需要你的验证码。
