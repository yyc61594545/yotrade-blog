注册 ChatGPT 账号时，OpenAI 有时会要求输入手机号接收验证码（现在多数情况下已不强制，见下方更新说明），一旦要求验证，中国大陆号码是用不了的。这是很多第一次尝试的用户卡住的第一道坎——账号密码都填好了，最后一步收不到验证码，只能放弃。

本文只讲**注册账号本身**这一步怎么解决没有海外手机号的问题，不涉及后续付费（付费方案见下方相关阅读）。

> **2026-09 更新**：目前多数情况下，普通注册和日常使用已经不再强制手机验证（OpenAI 帮助中心的说法是：创建账号和使用 ChatGPT 一般不需要手机验证；第一次在 platform 生成 API key 必须验证，Codex 桌面端也可能要求验证）。手机验证主要出现在四种情况：第一次创建 API key、Codex 登录、换设备或换网络后触发风控要求重新验证，以及部分地区和网络环境下的新账号注册。如果你正卡在其中一步，下面的方法依然适用。

## 一、为什么必须要海外手机号

一旦 OpenAI 要求手机验证，号码必须来自它支持的国家和地区，中国大陆不在支持列表里，所以 +86 号码过不了；官方同时写明不接受座机、VoIP（包括 Google Voice）和付费号码。这是平台的风控策略，用来降低批量注册和滥用账号的比例，几乎所有账号体系类似的海外产品（Google、AWS、Stripe 等）都有类似限制，不是针对 ChatGPT 单独设置的。

也就是说，问题不是"能不能绕过"，而是"怎么合法地拿到一个能收验证码的海外号码"。

## 二、可行方案对比

| 方案 | 原理 | 成本 | 稳定性 | 适合人群 |
|---|---|---|---|---|
| 接码平台 | 租用海外真实号码接收单次验证码 | 单次几毛到几元 | 中等，部分号段命中率低 | 只注册一次，不需要长期用这个号 |
| 虚拟运营商 eSIM | 购买美国/新加坡等地区**带号码、能收短信**的 eSIM 套餐（很多旅行 eSIM 只有流量没有号码，买前看清） | 几十到上百元/月 | 高 | 需要长期保留同一号码接后续验证 |
| 亲友海外号码 | 直接借用亲友在海外的手机号 | 免费 | 高，但依赖对方配合 | 有海外人脉资源的用户 |
| 海外交换生 / 留学生二手号 | 二手转让的当地实体卡号码 | 几十元起 | 因人而异 | 长期在同一账号体系深度使用 |

**接码平台**是目前最主流的方式，几乎所有教程都会提到，本质是第三方运营商把号码接码服务做成了产品，输入平台提供的号码，等对方转发验证码即可。缺点是号码是共享的，而 OpenAI 对同一个号码能用来验证的次数有上限（官方写明：第一次创建 API key 的验证，同一号码最多用 3 次），共享号码经常已被别人用过，所以成功率会随时间波动。

**eSIM 方案**适合打算把这个账号长期用下去、担心以后改密码/异地登录还要再收验证码的用户。花的钱多一点，但号码归自己独享，稳定性明显更好。

## 三、接码注册的具体步骤

1. 选择一个信誉较好、评价活跃的接码平台，注意查看该平台是否支持"OpenAI/ChatGPT"专项号码（部分平台会按用途分类定价）
2. 在平台上选择美国、英国或新加坡等 OpenAI 支持的地区的**手机号**（官方不接受座机、VoIP、Google Voice 和付费号码），完成小额付费下单。印尼、印度、越南等少数国家的号码，OpenAI 可能把验证码改发到 WhatsApp，接码号通常收不到，优先选美国、英国这类只走短信的号码
3. 打开 ChatGPT 注册页，正常填写邮箱、设置密码
4. 如果页面弹出手机验证（新注册不一定出现；第一次创建 API key、登录 Codex 时更常见），国家选对应地区，粘贴接码平台提供的号码
5. 回到接码平台页面刷新，等待验证码到达（一般 10–60 秒），复制粘贴回 ChatGPT 页面
6. 验证通过后立即完成后续资料填写，账号注册完成

**注意**：验证码到账后要尽快操作，多数接码号码有效期只有几分钟，超时该号码会被平台回收给下一个用户使用。

自己去接码平台的麻烦主要在前面几步：要先注册平台账号、通常要先充三十几块才能下单，界面多为英文或俄文，还得自己找国家和服务、自己判断超时和退号。如果你只需要一个码，也可以用我们的[美国号验证码代收](https://yotradeapi.com/sms?utm_source=blog&utm_medium=inline&utm_content=cn-chatgpt-register-without-foreign-phone)：¥29.90 一次，微信付款，付款后等你走到输手机号那一步再取号，验证码自动显示在页面上；收不到自动换号，换号仍失败全额退款。能否通过 OpenAI 的风控由对方决定，这一点任何接码方式都一样。

## 四、常见失败原因排查

- **提示"该号码已被使用"**：说明这个号码已经被别人拿去验证过（OpenAI 对同一号码的验证次数有上限，用满就不再接受），换一个号码重试，详见《[提示手机号已被使用或已关联其他账号怎么办](/blog/cn-chatgpt-phone-already-used/)》
- **验证码迟迟不到**：接码平台的短信通道偶尔延迟或被目标平台拦截，等待 1–2 分钟无果就换号
- **注册成功但很快被封**：OpenAI 不公开具体封号原因，号码来源只是可能因素之一，网络环境、使用行为也会被考虑；判断和申诉方法见《[ChatGPT 账号被封的判断与申诉实操](/blog/cn-chatgpt-account-banned-recovery/)》
- **提示地区不支持（unsupported country）**：OpenAI 说明，从不在支持列表里的地区（包括中国大陆）注册或创建 API key 会出现这个提示，这跟手机号无关，要先解决网络出口地区的问题，见《[ChatGPT 登录提示地区不支持怎么解决](/blog/cn-chatgpt-login-region-error/)》。号码地区与网络出口不一致会不会影响验证，官方没有说明，稳妥起见尽量保持一致
