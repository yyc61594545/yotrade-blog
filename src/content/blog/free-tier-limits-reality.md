"这个模型免费用"这句话在国内开发者社区里出现的频率极高，但真正把免费额度用满、用穿的人不多。多数人卡在两类问题上：一是根本不清楚免费额度的计量单位是什么（次数？token？时间窗口？），二是低估了免费层背后附加的隐藏限制——速率、并发、功能阉割、数据用途。这篇文章不讲"哪家免费"，讲"免费到底免费到什么程度"，帮你判断什么时候免费层够用，什么时候必须掏钱。

## 一、免费额度的四种计量方式

先分清楚免费额度到底按什么算，这决定了你能不能把它用满。

| 计量方式 | 代表服务 | 特点 |
|---|---|---|
| 固定 token/次数配额 | Google AI Studio（Gemini 免费层） | 每天重置，超额直接拒绝请求 |
| 时间窗口内速率限制 | Anthropic Console 免费额度（新账号赠送） | 一次性额度用完不重置，需要绑卡才能继续 |
| 功能降级式免费 | ChatGPT 网页版免费版 | 不按 token 算，按"每 3 小时几条消息"计，模型也会被降级到轻量版 |
| 完全免费但限速极严 | DeepSeek 官方 API 早期活动价/免费额度 | 高峰期排队、超时率高，实际可用吞吐远低于宣传值 |

四种模式对应四种"用穿"的方式：配额型是硬顶，一超就 429；窗口型是一次性的，用完要么等下一轮活动要么被迫升级；降级型不会报错但体验肉眼可见变差；限速型不报错但等待时间会吃掉你的开发效率。判断自己适合哪种免费层之前，先确认对方是哪一类，否则很容易把"免费"理解成"无限"。

## 二、免费层最容易被忽略的三个隐藏门槛

### 1. 免费额度往往不含最新模型

几乎所有厂商的免费层默认路由到旧模型或轻量模型，而不是官网首页宣传的旗舰模型。比如网页端免费版聊天工具在高峰期会自动降级到更小的模型来省算力，你以为自己在用旗舰模型，实际输出质量已经打了折扣。做效果评测或者给客户演示之前，一定要确认免费层实际调用的模型版本，不要用免费层的效果去外推付费层的效果，两者可能不是同一个模型。

### 2. 免费额度经常绑定"仅测试用途"的服务条款

多数免费层的服务条款里都有"不得用于生产环境"或"数据可能被用于模型训练"的条款。如果你在做的是一个即将上线的产品功能，免费层的合规风险比额度本身更值得关注，相关的数据合规要点可参考 [国内 LLM 应用数据合规要点：开发者必知的法规框架](/blog/cn-llm-data-compliance/)。

### 3. 免费额度的并发限制通常比总量限制更致命

很多人只关注"每天/每月能调用多少次"，却忽略了免费层几乎都配有极低的并发上限（QPS 或 RPM），这个限制常见的处理方式在 [LLM API 限速（Rate Limit）处理完整指南](/blog/llm-rate-limit-handling/) 里有详细拆解。哪怕你总量还有富余，一旦并发超限就会连续收到 429，表现上和"额度用完"几乎无法区分，容易误判成账户异常。

## 三、实测：免费层撑到多久会露馅

按典型使用场景做个粗略估算（数字仅作参考，具体以各服务当期政策为准）：

- **个人学习/写 Demo**：单人低频调用，免费层通常能撑很久，是最适合免费层的场景。
- **小工具日常使用**（比如给自己写的效率脚本、浏览器插件）：如果调用频率在每天几十到一两百次之间，多数免费层能覆盖，但一旦叠加多个功能同时调用同一个免费额度，很容易在月底前提前用穿。
- **给团队/小范围用户试用**：这是免费层最先露馅的场景。三五个人同时用同一个免费账号，并发限制会先于总量限制触发，体验上表现为"时好时坏"，排查起来比额度耗尽更麻烦。
- **对外提供服务（哪怕是免费产品）**：免费层几乎必然不够用，且服务条款通常明确禁止转售或对外提供服务，这一步必须切换到正式付费账户。

判断自己该不该迁移到付费层，可以参考这个简化流程：

```
是否面向多用户/生产环境？
├─ 是 → 直接上付费账户，不要用免费层硬撑
└─ 否 → 是否频繁触发 429/并发限制？
    ├─ 是 → 免费层容量已见顶，评估是否升级
    └─ 否 → 继续用免费层，定期复查配额消耗趋势
```

## 四、免费额度用不够之后的几条路

免费额度撑不住之后，常见的下一步不是立刻上最贵的方案，而是按需求精细化选择：

- **低频但偶尔爆发的场景**：优先看按量付费而不是订阅制，避免为闲置额度付钱，具体的成本对比方法可以参考 [月预算 ¥150 用什么 AI 工具最值：新手选型指南](/blog/cn-ai-tool-budget-150-rmb/)。
- **稳定高频调用**：这时候订阅制或者预付费套餐往往比按量付费更划算，同时要重新审视 Prompt 设计、缓存、批处理等成本优化手段，参考 [LLM 成本优化 30 条 checklist](/blog/llm-cost-optimization-checklist/)。
- **担心撞上正式付费账户的限速门槛**：付费不等于不限速，Anthropic、OpenAI 等厂商的付费层依然有 Tier 分级限速，具体规则见 [Anthropic Tier 限制与升级路径详解](/blog/anthropic-tier-limits-cn/)。
- **国内访问的额外成本**：免费层大多数情况下无法直连，需要额外考虑网络与账号问题，这部分和纯粹的额度问题是两个维度，可参考 [国产大模型 vs 海外大模型成本对比：中国开发者怎么选](/blog/cn-llm-cn-vs-overseas-cost/) 里关于综合使用成本的讨论。

## 五、免费层够用时也建议做的两件事

即便当前免费额度完全够用，也建议提前做两件事，避免临时抱佛脚：

1. **记录每日/每月实际消耗曲线**，哪怕是手动记录几周的调用量，也能在额度快用完前预判，而不是等到 429 报错才发现问题。
2. **提前跑通付费账户的接入流程**（哪怕暂时不用），包括支付方式、API Key 获取、中转服务配置等，真正需要切换时能当天完成，不会因为临时办卡、绑卡失败卡住项目进度。
