关于 Midjourney 注册，网上大量教程还停留在「建 Discord 账号 → 加官方服务器 → 在频道里打 `/imagine`」这套流程。这套流程现在**仍然能用，但已经不是唯一路径，而且对新手来说是更麻烦的那条**。

`midjourney.com` 的网页版早就能独立出图了，Discord 从「必经之路」变成了「可选入口」。这篇按现在的实际情况把流程重排一遍，说清每一步到底要不要做、哪一步最容易卡住。

## 一、先搞清三条入口的关系

| 入口 | 需要 Discord 吗 | 适合谁 | 主要限制 |
|---|---|---|---|
| `midjourney.com` 网页版 | 首次注册通常仍需 Discord 或 Google 账号登录 | 绝大多数人 | 无 |
| Discord 官方服务器 | 必须 | 习惯社区玩法、想看别人的 prompt | 公共频道出图对所有人可见 |
| 自建服务器 + 邀请 Bot | 必须 | 团队协作、要私有频道 | 配置一次性成本 |

**最关键的一条认知**：Discord 账号在这里的角色是**身份凭证**，不是使用场所。也就是说你可能仍然需要一个 Discord 账号来登录，但**出图完全可以在网页上做**，不必学 Discord 的那套斜杠命令和频道规则。

对新手的建议很直接：**用 Discord 账号登录，但在网页版出图。** 这样既绕过了 Discord 的操作门槛，又避免了公共频道里出图内容对所有人可见的问题。

## 二、第一步：建 Discord 账号

如果你已有 Discord 账号，跳到第三节。

注册本身很简单——邮箱、用户名、密码、生日。真正的卡点有两个：

**卡点一：手机验证。** Discord 会在它判断账号可疑时要求手机号，国内 IP 注册触发概率不低，而 `+86` 号码在多数情况下不被接受。这一步的完整处理（什么时候触发、一个号码能绑几个账号、被临时封禁怎么办）在《[Discord 手机验证国内怎么过](/blog/cn-discord-phone-verify-cn/)》里已经写得很细，这里只提一条最重要的：**一个号码只能绑一个 Discord 账号**，所以别想着一个号码把家人朋友的账号都验了。

**卡点二：注册后立刻被要求「验证邮箱」但邮件不来。** 先查垃圾箱，再确认邮箱地址没打错。别在同一个邮箱上反复点重发，Discord 对重发有限流，点多了反而更慢。

建好账号之后，**先在 Discord 里把两步验证开起来**，用验证器 App 而不是短信。理由是 Discord 账号现在是你 Midjourney 的身份凭证，它丢了 Midjourney 也一起丢。

## 三、第二步：登录 midjourney.com 并绑定

访问 `midjourney.com`，点登录，选「Sign in with Discord」（部分时期也提供 Google 登录）。跳转到 Discord 的授权页，点同意，回到 Midjourney。

这一步会问你几个偏好问题（喜欢的风格等），可以随便选，不影响后续，之后在设置里能改。

有一个小细节值得注意：**授权时 Discord 会列出 Midjourney 要读取的权限。** 正常情况包含读取你的账号基本信息和加入服务器的能力。如果你看到要求「管理服务器」之类的权限，说明你点进的不是官方入口，退出重来。

## 四、第三步：必须先订阅才能出图

这是最多人卡住的地方，而且没有办法绕：**Midjourney 没有免费试用额度。** 早期那个「免费 25 张」的政策在被大规模滥用之后就取消了，现在不订阅什么都做不了。

套餐结构大致是按**月度 GPU 时长**分档的，从入门档到最高档，差别主要在：

- **Fast 模式的 GPU 时长**（决定你每月能快速出多少图）
- **是否有 Relax 模式**（不限量但排队，中低档没有）
- **Stealth 模式**（出图不进公共画廊，仅高档套餐提供）

选择建议：**第一个月一律选最低档月付。** 原因是多数人对自己的实际用量估计得很不准——你以为会天天出图，实际上第一周新鲜感过了就停了。等你真的把低档额度用完，再升档，Midjourney 支持中途升级。**不要一上来就年付**。

对国内用户来说，订阅环节的真实难点不是选套餐而是**付款**：Midjourney 的收银台不接受国内普通银行卡直付，这是独立于 Midjourney 本身的问题。套餐细节和付款路径可以参考姊妹站的《[Midjourney 2026 订阅指南](https://www.yotradellc.com/blog/midjourney-2026-subscription-guide)》。

## 五、第四步：第一次出图

网页版的操作只有一个输入框，把描述写进去回车即可。几个上手就该知道的点：

**参数写在 prompt 后面，用 `--` 开头。** 网页版有 UI 面板可以调，但了解参数写法在你想复用别人的 prompt 时很有用：

```
a quiet courtyard in early morning fog, ink wash style --ar 16:9 --stylize 250
```

- `--ar` 控制画面比例（`16:9`、`3:4`、`1:1`）
- `--stylize` 控制模型自由发挥的程度，数值低更贴近你的描述，数值高更"好看"但可能偏离
- `--no xxx` 排除某些元素

**一次生成四张，不要急着重开一轮。** 看到四张里有接近的，用 Vary（微调）或 Upscale（放大）比重新写 prompt 更省额度，这是省 GPU 时长最有效的习惯。

**中文 prompt 能用，但英文效果更稳。** 不是中文不支持，而是模型训练数据里英文描述的密度高得多。折中做法：中文想清楚要什么，让任意一个 AI 对话工具帮你转成英文描述。

## 六、国内最容易卡住的三个环节

按实际发生频率排序：

**第一：Discord 的手机验证。** 前面说过，处理方式见专文。这里补一条判断标准——如果你注册 Discord 时没被要求手机号，**别主动去账号设置里绑**。很多人出于"先准备好"的心理主动绑定，结果反而占用了号码的配额。

**第二：订阅付款被拒。** 这一步失败时不要反复重试同一张卡。连续失败的刷卡记录本身会被风控系统记下，后面就算换了可用的付款方式也可能被连带拒绝。第一次失败后就该换路径，而不是再试五次。

**第三：网络环境不稳导致出图中断。** Midjourney 的出图是流式返回进度的，链路抖动会让进度卡住。判断方法：刷新页面看任务是否还在队列里——通常任务在服务端仍在跑，只是你的连接断了，等一会儿刷新就能看到结果，**不要重复提交同一个 prompt**，那是实打实地多花额度。

## 七、注册完成后的四个自检项

1. **Discord 两步验证开了吗？** 用验证器 App，不用短信。
2. **手机号如果不是你自己的，摘掉了吗？** 共享号池的号码迟早会到别人手里，绑在恢复链条上是风险，机制见《[用接码收验证码安全吗](/blog/cn-sms-receive-safe-or-not/)》。
3. **出图是公开的吗？** 中低档套餐的图默认进公共画廊。如果你在做商业或私人内容，这件事要提前知道，而不是发现之后才知道。
4. **续费日期记下来了吗？** Midjourney 是自动续费，不想续的话要提前在设置里取消，到期当天取消已经来不及。

## 八、常见问题

**Q：不用 Discord 能注册 Midjourney 吗？**
目前登录环节多数情况下仍需要 Discord 或 Google 账号作为身份凭证，但**出图不需要在 Discord 里做**。这两件事经常被混为一谈。

**Q：Discord 账号被封，Midjourney 订阅还在吗？**
订阅本身在 Midjourney 侧，但你可能登不进去。这是把身份挂在第三方账号上的固有风险，也是要给 Discord 开两步验证的根本原因。

**Q：可以多人共用一个 Midjourney 订阅吗？**
不建议。多设备多地点登录是触发账号异常判定的典型模式，而且额度是共享的，实际体验很差。团队用法应该走自建服务器 + Bot 的方式。

**Q：出的图能商用吗？**
取决于你的套餐和 Midjourney 当期的服务条款，不同档位的授权范围不同，而且条款会调整。**需要商用时以官方条款当期文本为准**，不要依据任何二手教程（包括本文）的描述做决定。

**Q：额度用完了但不想升档怎么办？**
中高档套餐有 Relax 模式可以继续出图（排队慢但不计 Fast 时长）。低档套餐没有这个选项，只能加买 Fast 时长或等下个周期。
