号码填好了，点了 "Send code"，页面跳到输入验证码的界面——然后就没有然后了。等一分钟，没有；再点一次重发，还是没有；点到第四次，页面直接提示尝试次数过多。

这种状况最消耗人的地方在于：**你不知道该继续等，还是该换号。**很多人就是在这里反复重试，把一个本来能用的号码试废了。这篇给一套固定的排查顺序，按顺序走，每一步都有明确的"继续"或"放弃"判据。

## 一、先确认你是不是真的需要这个验证码

听起来多余，但确实有人在不需要验证的场景里死磕。2026 年 OpenAI 的手机验证并不是处处都要：

| 你在做什么 | 是否需要验证码 |
|---|---|
| 注册账号、日常网页聊天 | 多数情况不需要 |
| 第一次创建 API Key | 需要，账号级验证一次 |
| Codex CLI / IDE 插件首次登录 | 需要，同一套验证 |
| 换设备、换网络后被风控拦下 | 可能需要，重新验证 |
| 登录时提示地区不支持 | **不需要**，这是另一类问题 |

如果你其实卡的是"地区不支持"，那再多验证码也解决不了，处理方式完全不同，见文末相关阅读。确认自己确实站在手机号输入框前面，再往下走。

## 二、第一层：页面到底有没有把短信发出去

这一层最常被跳过，但它能解释很大一部分"永远收不到"。

**看点了发送之后页面的反应。**正常情况下页面会立刻跳到验证码输入框，并显示倒计时或 "Resend code" 变灰。如果出现下面几种情况，说明短信压根没发出去：

- 点击后页面没动、按钮一闪又恢复 → 请求被拦截，多半是网络出口问题
- 立刻弹红字 "This phone number is not supported" → 号码在黑名单层被拒，短信不会发
- 提示 "Too many attempts" → 触发频次限制，这次不会发，等 24 小时

**重复输入国家码是高频低级错误。**输入框左侧已经选了 +1，右边再填 `1650...`，实际提交的号码是 `+11650...`，格式非法。有些页面会直接报错，有些会静默失败——填号码时只填区号之后的部分。

判据：**如果页面没有正常进入倒计时状态，就不是"收不到"，是"没发出"，等多久都没用。**

## 三、第二层：号码侧

页面确实发出去了，那就看号码这一端。

**号码类型。**能收到 OpenAI 短信的是真实运营商号码（实体卡、eSIM、接码平台手里的运营商号）。Google Voice、TextNow 这类纯 VoIP 号 2026 年基本被识别拦截。麻烦的是它有时不是明着拒绝，而是显示"已发送"但短信永远不到——所以别把"页面说发了"当成号码合格的证据。

**号码被用过太多次。**同一个号码能验证的 OpenAI 账号数量有限（具体阈值 OpenAI 未公布，视作近似参考）。超限的号码，有时报错，有时也是静默不到。接码平台的廉价号段最容易踩这个。

**接码平台侧没刷新。**如果你用的是接码平台，短信到平台不等于自动推给你——部分平台需要手动点刷新。等了两分钟之前，先手动刷一次页面。

**号码所在国家。**美国号在 OpenAI 各个验证环节的表现最稳定。其他国家的号段不是不能用，而是命中率波动更大，尤其在 Codex 授权页和 platform 创建 Key 这两个入口。

判据：**超过 2 分钟没到，换号比继续等有效。**短信通道正常时,验证码通常 10–60 秒到达；两分钟没来，大概率是这条号码这一次就是不行，而不是"再等等就来了"。

## 四、第三层：网络侧

这一层影响的不是短信本身，而是你和 OpenAI 页面之间的请求。

- **出口地区与号码地区差异过大**：国内 IP 配美国号码，部分风控策略会把这次验证升级或直接静默丢弃。尽量让网络出口和号码地区一致。
- **出口 IP 被大量共享**：公共节点上有太多人做同样的事，触发 IP 维度的频次限制，表现同样是"发了但不到"。
- **请求被中途拦截**：页面加载正常但接口请求失败，看浏览器控制台 Network 面板有没有红色请求，是最快的判断方式。

网络这一层的特点是：**换个出口就好了，或者换了也一样。**试一次就能分辨，不值得反复调试。

## 五、第四层：重试节奏

这是最容易把事情搞砸的一层。正确的节奏：

```text
点发送 → 等 60 秒
  ├─ 收到 → 立刻填，别拖（接码号有效期通常只有几分钟）
  └─ 没收到 → 再等 60 秒
       ├─ 收到 → 同上
       └─ 还没有 → 换号，不要对同一个号码重发第三次
```

**为什么不该反复重发？**同一号码连续重发会同时消耗两个额度：号码侧的可用次数，和账号侧的尝试次数。前者让这个号码彻底作废，后者会让你的账号被锁 24 小时——最后你手里既没有能用的号，也没有能试的窗口。

**换号比重试有效**，这是整篇文章最值得记住的一句。

## 六、什么时候该停下来换方案

如果你已经换了两三个号码都不行，问题大概率不在号码上：

- 都是同一家接码平台的号 → 这家的号段可能整体被标记，换平台或换获取方式
- 都是 VoIP 号 → 方向就错了，必须换真实运营商号码
- 换了真实号码也不行 → 回头看第一层和第三层，多半是页面根本没发出去，或者网络出口有问题

## 七、一张自查清单

卡住的时候按这个顺序过一遍，通常两分钟内能定位：

1. 我真的在手机验证这一步吗？（不是地区限制、不是登录失败）
2. 点发送后页面有没有进入倒计时？没有 = 没发出去
3. 国家码有没有重复输入？
4. 号码是不是真实运营商号？VoIP 直接排除
5. 接码平台页面手动刷新过了吗？
6. 从发送到现在超过 2 分钟了吗？超过就换号
7. 同一个号码已经重发几次了？超过两次就停手
8. 网络出口地区和号码地区一致吗？
